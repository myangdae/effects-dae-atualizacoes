# SafeLayer Editor · atualizações

Instaladores do **effects dae**, editor de imagens, vídeos e motion da **Bingzhan Studios** (equipe **Aurea Sub Studio**).

Este repositório só guarda as versões publicadas (em **Releases**). O código do editor fica num repositório privado.

## Baixar

Na página de [Releases](https://github.com/myangdae/effects-dae-atualizacoes/releases/latest):
- `effects-dae-<versão>-instalador.exe` — instala no Windows e **se atualiza sozinho**;
- `effects-dae-<versão>-portatil.exe` — roda sem instalar; avisa quando há versão nova.

Depois de instalado, o app procura atualizações ao abrir e a cada 6 horas, baixa em segundo plano e avisa quando o patch estiver pronto.
